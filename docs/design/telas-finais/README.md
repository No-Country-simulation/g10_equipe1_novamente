# Capturas das Telas finais

Estas imagens são capturas do arquivo `[Telas finais] NovaMente jornada com modelos de conteúdo.html`, no Drive da equipe. Esse arquivo é a única fonte de layout do produto. Os agentes não conseguem abrir as imagens do Drive, então as telas que um ticket usa ficam aqui.

As capturas foram feitas em 18/11/2026, em um Chromium sem interface, com 1440 px de largura.

| Arquivo | Tela das Telas finais | Ticket |
| --- | --- | --- |
| [`tela-5-curso.png`](tela-5-curso.png) | 5 · Roadmap do curso | T18 |
| [`tela-6-conteudo-tutorial.png`](tela-6-conteudo-tutorial.png) | 6 · Conteúdo (tutorial estático, sem índice) | T18 (moldura), T08 (leitor) |
| [`tela-q1-quiz.png`](tela-q1-quiz.png) | Q1 · Quiz comentado, aguardando resposta | T18 (moldura), T10 (leitor) |
| [`tela-f1-flashcards.png`](tela-f1-flashcards.png) | F1 · Flashcards, frente | T18 (moldura), T09 (leitor) |

As capturas mostram o design, não o produto. O progresso, o botão "Finalizar" e outros elementos ficam fora do MVP. O ticket de cada tela diz o que entra e o que sai.
